# Repo notes

This repo (russlib/test1022A, local name TutorialsOrBugs) holds small
tutorial exercises and bug reproductions. Conventions:

- One folder per experiment or tutorial, named for the topic.
- Bug repros include the failing snippet plus a short writeup of the
  expected vs actual behavior and the environment.
- Nothing here is production code; anything can be rewritten freely.

Maintained across machines via the handoff/neaten/reconcile sync pipeline.
